# 📝 MosquitoNotes 🦟
Aplicativo para uso pessoal feito em SwiftUI para gerar rapidamente notas padronizadas das gravações de mosquitos na bolsa de Iniciação Científica.  
Permite registrar informações como idade, umidade, método de criação e observações adicionais, exportando tudo em arquivo de texto.

## Uso
1. Abra o projeto no **Xcode** (versão 14+)
2. Execute com ⌘R ou crie o build do app com ⌘B
3. Abra ou crie um novo arquivo
4. Preencha os campos de anotação e clique em **Adicionar nota**
5. Pronto ;)
